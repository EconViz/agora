# Security Policy

## Scope

This repository holds the EconViz manuals: Typst sources, figure scripts and
fonts. Security issues in a package itself belong to that package's
repository, for example
[EconViz/utility-viz](https://github.com/EconViz/utility-viz/security).

Report here, for example, problems in the build scripts, or manual content
that recommends an unsafe practice.

## Supported versions

Only the latest commit on `main` is supported.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Instead, report them privately through [GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) ("Report a vulnerability" under the repository's **Security** tab), or by email to **contact@econ-viz.org**.

You can expect an initial response within 7 days.
